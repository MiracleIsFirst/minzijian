# Zijian Min · 闵子剑 — Academic Homepage

Static academic homepage for Zijian Min, designed for GitHub Pages.

## Pages

- `index.html` — research-focused landing page
- `research.html` — research agenda
- `publications.html` — selected publications
- `news.html` — academic news and milestones
- `cv.html` — web CV
- `assets/style.css` — responsive site styling

## Target URL

The intended public URL is `https://zijianmin.github.io`.

The connected GitHub account currently uses the username `MiracleIsFirst`, so GitHub will not serve this repository at the intended user-site URL until the account username is changed to `zijianmin` and the repository is named `zijianmin.github.io` under that account. Before renaming the account, this repository can instead be served as a project site under the current username if GitHub Pages is enabled.

## Maintenance

The site is plain HTML/CSS by design: no build system, Ruby, Jekyll, or Node dependency is required. Update publication and news entries directly in the corresponding HTML files.
